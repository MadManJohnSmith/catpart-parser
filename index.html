The decode climb — 3 days of the #34 grind

Accepted fitness runs only (ADR-0001 no-regret): the share of corpus parts whose geometry survives the sanity gate — non-empty mesh, manifold, finite bounds. Held-out parts are never used to tune a decode law.

Three CLIs, one job

Install once, then inspect, export and measure — everything fails closed with the specific gap named.

catpart-inspect

Schema-v1 JSON per file: header, container inventory with base-class annotation, document_name, trailer and detected version.

catpart-export

Facet geometry out of decoded stores — mesh sanity checked, curve-entry gaps warned, never guessed.

catpart-fitness

Corpus-wide L1/L2 scalars over Dev and held-out splits, with an append-only accepted-run history.

Quickstart

# from source (active development)
git clone https://github.com/MadManJohnSmith/catpart-parser
cd catpart-parser
pip install -e ".[test]"

# read a part file without CATIA
catpart-inspect bracket.CATPart
