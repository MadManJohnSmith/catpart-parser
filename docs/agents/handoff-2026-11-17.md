## 4. Environment Gotchas & Operational Commands

1. **Python Shared Library Path (CRITICAL on this host)**:
   - `.venv/bin/python` requires `libpython3.14.so.1.0` from `/usr/lib`. Always prefix Python/pytest/check commands with:
     ```bash
     export LD_LIBRARY_PATH=/usr/lib:${LD_LIBRARY_PATH:-}
     ```
   - Include this exact prefix in every `delegate_task` prompt so workers do not waste turns hitting `error while loading shared libraries: libpython3.14.so.1.0`.
2. **Pre-Push Verification Gate**:
   - `git push` automatically runs `scripts/check.sh` (~1.5–2 min). Always verify locally first:
     ```bash
     export LD_LIBRARY_PATH=/usr/lib:${LD_LIBRARY_PATH:-} && bash scripts/check.sh
     ```
3. **Subagent Rules (`AGENTS.md`)**:
   - **Never** use `invoke_subagent`.
   - Use `delegate_task` (`mode: "async"`, `isolation: "worktree"` for writers) so every worker has a visible card in T3 Code and wakes the orchestrator automatically on completion.
   - Follow T3 orchestration rules: call `orchestrator_capabilities` once at session start, never poll running delegates, and never silently switch models without checking quota/availability or user instruction.
