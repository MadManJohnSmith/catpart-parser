  named-ambiguity acceptable (`docs/agents/dispatch-recipes.md`).
- Review per ticket before merge — the verifier re-derives with its
  OWN walkers, never the child's functions. Coordinator-executed
  bounded fixes (G4) for small review findings.

  tracker (README.md) + Progress commit at every ticket close.

  generated artifact is fixed by fixing the generator and
  regenerating (never hand-edit); re-runs pass the record's EXACT
  output paths (the default-path naming follows SLICE/kind, not the
  record); close comments cite COMMITTED figures.
- Census/classifier discipline: --selftest synthetic negatives for
  every ceiling-feeding detector; detector-honesty declarations;
  negative claims get mechanical sweeps (the operation, not the
  word).
- The provider-failure playbook (dispatch-recipes.md): verify
  terminal state → clean the residual (incl. the
  substantial-uncommitted-residual branch: snapshot the diff to
  ~/.local/state, re-dispatch fresh with the patch as
  epistemically-labeled reference) → never dispatch from a
  notification-woken run → re-dispatch as a NEW delegate.
- Pre-commitment gating: when a run's data could contaminate a
  pre-commitment, gate the run structurally and split
  build/declare/run across phases (the V5 shape).
- Suite stays corpus-free; corpus binaries never committed; the
  fitness history is append-only; no-regret: no fitness row changes
  without the full discipline.
