## 2. The byte-level carrier (both bases)

A shell contributes **no bytes of its own**. Its carrier is the facet record population, whose grammar was decoded by G3 and re-measured by BR2 — cited here with both offset bases so every shell figure traces to a byte position:

| offset | field |
| :--- | :--- |
| `+0x00 (0d)` | marker byte `01` |
| `+0x01 (1d)` | marker `mk` (`0x41`-`0x4f`; the pinned soup families are `0x41`/`0x42`/`0x49`/`0x4a` strips and `0x4c` rings) |
| `+0x02 (2d)` | `ty` = loop count (TOP-05 law, BR2 §3) |
| `+0x03 (3d)` | form byte `ff` (4-byte header form) |
| `+0x04 (4d)` | `u32le n` — total reference count (`+0x04 (4d)`..`+0x08 (8d)`) |
| `+0x08 (8d)` | 12B normal, three f32le components (`nx` `+0x08 (8d)`, `ny` `+0x0c (12d)`, `nz` `+0x10 (16d)`; markers `0x49`/`0x4a`/`0x4c`) |
| `+0x14 (20d)` | `ty` count integers, `count_width` bytes each (u8, or u16be big-endian) |
| `+0x14 (20d) + ty*count_width` | `n` references, `ref_width` bytes each (u8 or u16be big-endian), **lexicographic ranks** into the pool (G3 F2/C8) |

Record end: `+0x14 (20d) + ty*count_width + n*ref_width`. The reference width is per-record; the normal is little-endian f32; the counts and references are the only topology bearing fields the shell law reads. **There is no field to add**: the shell partition is a function of the record set's references, and §5 shows no record class is left over that could carry a shell identity.

## 3. The partition law (decoded)

Input: the store's flattened pool (walk order, G3's soup convention) and its accepted facet records. Steps, exactly as shipped in `catpart.brep.shell.decode_shells`:

1. **Faces** are the accepted records on the pinned soup markers (`0x41`/`0x42`/`0x49`/`0x4a` strips, `0x4c` rings), decoded by the shipped export reading (`facets.decode_soup`: strip `(r_t, r_{t+1}, r_{t+2})` with the odd-`t` flip, polygon fan from the first corner, the G3 F7 degenerate skip). The partition is therefore over exactly the triangles the exporter emits — pinned by `test_partition_triangles_match_the_shipped_soup`.
2. **Adjacency** joins two faces when they share an **undirected triangle edge** (a vertex pair in lexicographic-rank space). Proximity and vertex-only contact do not join faces.
3. A **component** is a maximal connected face set. Its invariants: `edge_count` (distinct undirected edges), `boundary_edges` (edges used exactly once), `max_edge_degree` (worst usage), `oriented` (no directed edge traversed twice), `signed_volume = sum dot(a, cross(b, c))/6` in the exported winding.
4. **Status**: `closed-manifold` — every edge exactly twice and no edge above twice (the TOP-03 signature, `boundary_edge_count = 0`); `open` — at least one boundary edge (G3 F6's open-shell class); `non-manifold` — an edge used more than twice.
5. A store's shell set is **complete** (`all_faces_closed`) when it has at least one component, every component is a shell, and no face-candidate record is unplaced or degenerate.

Scope: the law is applied to **pool-only stores only** (281 of 1,317 located stores, BR6S-07). On a composite store the references leave the pool, so no geometry — and therefore no shell — is claimed; a face record with an out-of-pool reference on a pool-only store is counted (`unplaced_faces`), never guessed into a component or silently dropped.

## 5. The negative: a shell is not a stored record

The TOP-03 construct resolves as **decoded** on the partition law, with an explicit negative for the "stored shell record" hypothesis. The sweep is arithmetic, not rhetorical:

1. **Every accepted record is a facet record.** The accepted population splits into exactly three classes: 2,042 pool-only face candidates (BR6S-19), 116,057 composite face candidates (BR6S-23) and 708 composite `0x44` records (BR6S-22 / BR6S-22b). Their sum is 118,807 — an accounting identity by construction (BR6S-23b), anchored independently by BR2's accepted-record volume, also 118,807 (BR2-07/BR2-08). No residual record class exists that could enumerate shells, face sets or a shell count.
2. **The pool-only stores carry no `01 02` pool-group edge table.** 0/281 pool-only stores carry an `01 02` edge group or an `ff` trailer opener (BR6S-24, BR6S-24b) — a structural zero, because the pool-only/composite split is the same F8 predicate (BR6S-07/08), so the detector's ability to fire is committed as a positive control on the other scope: 996/1,036 composite stores carry the `01 02` group (BR6S-24c) and 399 carry the trailer opener (BR6S-24d). G3 F8's 6-byte edge table is thus a composite-scope carrier, and the edge/curve carriers BR3 did decode cannot substitute for it: the `01 01 <count>` unwrapped edge lists and the `33 32` curve records (BR3's `T06_edge_presence`, 1,224/1,442 corpus files carrying an edge group, an unwrapped list or a `33 32` record; `C01_line_walked`, 508,138 corpus `33 32` records walked) enumerate edges and curve parameters, never a face set. The edge list a shell partition would otherwise come from does not exist on the decodable scope; the partition is reconstructed from shared vertex references.
3. **The one unread marker is a face family, not a shell enumerator.** All 708 unread records are on marker `0x44` (BR6S-22), all on composite stores and none on the 281 pool-only stores (BR6S-22b). They parse under the shared facet grammar — `n` equals the sum of their count bytes in 708/708 records (BR6S-22c), so the record frame is the facet frame — and their references run into the composite index space (318/708 run past the pool end, BR6S-22d), the same space that excludes their stores from the partition. `0x41`/`0x49` are not unread: they are pinned strip markers (G3 F10 candidate semantics) already counted inside the 2,042/116,057 face-candidate populations (BR6S-19 / BR6S-23), and `0x4b`/`0x4e` occur zero times among the accepted records. A shell record would carry no vertex references at all.

Consequence for the graph step: the B-rep assembler must **derive** shells from the face set (as `shell.decode_shells` does), not read them from a store field.

## 7. Detector honesty (per class: what the detector does NOT discriminate)

- **Census `TOPO_SHELL` detector (facets_total > 0)**: does NOT discriminate a shell from any face set — it fires on every part with an accepted facet record (1,133, BR6S-02) regardless of closure, which is why 66 parts resolve (BR6S-04) while the detector rate reads 1,087/1,089 = 0.998163 (BR6S-01). Negative fixture: the open sheet (`test_negative_sheet_with_paired_edge_is_open`) — two face records present, so the detector fires, yet the single edge-connected component has boundary edges and the closure law labels it open.
- **Closed-manifold class**: does NOT discriminate orientation or B-rep identity — closure counts edges, not winding, and a tessellated curved surface closes exactly like a B-rep shell. Negative fixtures: the inward-flipped face of a closed tetrahedron (`test_negative_closed_is_not_oriented`: still a shell, not oriented) and the closed octahedron (`test_negative_closed_octahedron_has_no_brep_identity`: one shell, no B-rep face identity).
- **Open class**: does NOT discriminate a genuine open sheet from an incomplete placement (a face that failed to place would look like a boundary edge); the counts are kept separable — 531 unplaced records (BR6S-20) versus 69 open components (BR6S-14). Negative fixtures: the open sheet above and the out-of-pool record (`test_negative_out_of_pool_refs_are_counted_not_guessed`: counted, no component).
- **Non-manifold class**: does NOT discriminate real non-manifold geometry from a byte-parse width error — G6's width-rank defect produced the same edge-degree signature on composite stores (`scripts/triage/not_manifold_audit.py`); measured 0 on the pool-only scope (BR6S-15), so the class is unpopulated here and not load-bearing. Negative fixture: three faces on one edge (`test_negative_edge_used_three_times_is_non_manifold`).
- **Adjacency (all classes)**: does NOT discriminate contact from connectivity — faces touching at one vertex, or coincident faces, are separate components. Negative fixture: the vertex-sharing tetrahedra (`test_negative_vertex_sharing_tetrahedra_are_two_shells`: two closed components that share exactly one vertex, not one; a vertex-proximity union-find would merge them).
- **Role (all classes)**: no byte marks an outer shell versus a cavity shell; signed volume is reported as a measurement (positive under the exported winding, 76/76, BR6S-17), never as a role. Negative fixture: the reversed tetrahedron (`test_negative_reversed_tetrahedron_negative_volume`: closed, negative volume).
- **Shapeless records**: a placed record whose primitive reading yields no non-degenerate triangle is counted, not dropped (0 measured, BR6S-21). Negative fixture: the all-same-vertex ring (`test_negative_degenerate_face_yields_no_component`).

All fixtures run in `tests/test_brep_shell.py` and via `scripts/triage/decode_brep_shell.py --selftest` (0 failures).
