| **0x52** | **0** | 0 | **does not exist** |

- The `30 04 XX` family carries **XX=04 in 378,501/378,501 hits** (W13-02):
  no sibling prefix exists.

  (378,501/378,501, uncapped; W13-03). The apparent 378,501-vs-190,278
  discrepancy between census regexes is the 8-byte-stride chain
  double-counting, not a sibling.
- `30 04 05 ...` and `d2 d2 52` are pinned fail-closed by tests.

## Reopening criteria (what would change the verdict)

1. **A corpus sample where a non-wired flag closes byte-exact under a
   concrete law**: any future binary with `d2 d2 52` (or a new
   acquisition batch adding `30 04 XX≠04` hits) — run `census` first;
   if a flag class appears with in-span positions, decode it against
   the W4 grammar (`kind + N_tris/N_strips/N_fans` at +57, u16be
   stream, byte-exact closure at `rel_len-1`) before wiring.
2. **A shown edge record that provably carries triangle indices**
   (mult-3 in-bounds stream over a declared array): today 0/1055 have a
   declared array in-record; a file where the between-spans record
   indexes an EXTERNAL array (span pairing across boundaries) would
   need a new pairing law — the W4 FG2-07 negative covers the
   before-first-record subset (32/33 without clean window arrays).
3. **The trailing-bytes families become flip-relevant**: if a future
   baseline has empty-mesh files whose ONLY in-span records sit in the
   −4/−2/+0/−10 delta families, a bounded tail convention (read ≤ 5
   trailing u16be values, all mult-3, then close) is the first candidate
   — wire it per-kind with the strict gate and measure flips on THAT
   population only.
